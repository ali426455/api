# 🤖 ربات اسکالپ EUR/USD - استراتژی هیبرید

ربات معامله‌گری فارکس با استراتژی هیبرید (قوانین تکنیکال + هوش مصنوعی) برای جفت ارز EUR/USD در تایم‌فریم ۵ دقیقه‌ای.

## ✨ ویژگی‌ها

- **استراتژی هیبرید**: ترکیب قوانین تکنیکال (EMA, RSI, ATR) با پیش‌بینی‌های Kronos AI
- **بک‌تست کامل**: شبیه‌سازی معاملات با معیارهای عملکرد (Win Rate, Profit Factor, Sharpe, Drawdown)
- **داشبورد زنده**: نمایش سیگنال‌ها و سطوح ورود/خروج
- **مدیریت ریسک**: محاسبه خودکار حد ضرر و تارگت‌ها بر اساس ATR
- **قابل تنظیم**: تمام پارامترها قابل تغییر هستند

## ⚙️ تنظیمات استراتژی

در سلول مرحله ۳ نوت‌بوک، پارامترهای زیر را تغییر دهید:

```python
STRATEGY_CONFIG = {
    'trend_ema_fast': 20,         # دوره EMA سریع
    'trend_ema_slow': 50,         # دوره EMA کند
    'rsi_period': 14,             # دوره RSI
    'rsi_oversold': 30,           # سطح اشباع فروش
    'rsi_overbought': 70,         # سطح اشباع خرید
    'risk_reward_1': 1.0,         # نسبت سود به ریسک تارگت ۱
    'risk_reward_2': 1.5,         # نسبت سود به ریسک تارگت ۲
    'risk_reward_3': 2.5,         # نسبت سود به ریسک تارگت ۳
    'atr_sl_multiplier': 1.5,     # ضریب ATR برای حد ضرر
    'min_confidence': 65,         # حداقل درجه اطمینان
}
```
